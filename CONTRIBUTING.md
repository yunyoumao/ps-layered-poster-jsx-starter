# Contributing

Contributions are welcome if they keep the starter template public-safe and generic.

Good contributions include:

- Better JSX compatibility notes.
- Cleaner layer naming.
- Safer export behavior.
- Synthetic template variants.
- Better validation tests.

Before opening a pull request:

- Use fictional poster content only.
- Do not commit PSD/PSB files, paid fonts, real conference posters, unpublished figures, lab images, local paths, or credentials.
- Run `python -m unittest discover -s tests`.
- Run `python scripts/validate_public_assets.py`.
