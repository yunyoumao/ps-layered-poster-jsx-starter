# Photoshop JSX Notes

This starter uses ExtendScript JSX for Photoshop automation.

The public script intentionally keeps the design generic:

- no paid fonts;
- no real conference poster content;
- no real QR code;
- no private research figures;
- no PSD/PSB assets committed to Git.

The generated document is a starting point. Review every layer name, text layer, figure placeholder, and export setting before using a private copy for real work.
